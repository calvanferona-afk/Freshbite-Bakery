# FreshBite Bakery Website

A responsive multi-page bakery website built with HTML5, Bootstrap 5, CSS, and JavaScript.

## Pages

- Home (`index.html`)
- About (`about.html`)
- Menu (`menu.html`)
- Events & Catering (`catering.html`)
- Gallery (`gallery.html`)
- Contact (`contact.html`)

## Publish with GitHub Pages

1. Sign in to GitHub and create a new public repository, for example `freshbite-bakery`.
2. Upload **all files and folders from this package** to the repository root. Make sure `index.html` is at the top level, not inside another folder.
3. Open the repository's **Settings**.
4. Select **Pages** under **Code and automation**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select the `main` branch and the `/ (root)` folder, then click **Save**.
7. GitHub will display the published website address after deployment.

For the GitHub account `calvanferona-afk`, the expected address will be similar to:

`https://calvanferona-afk.github.io/freshbite-bakery/`

## Notes

- This is a static website and works on GitHub Pages without PHP.
- The contact and catering forms are demonstrations and show an on-screen confirmation; they do not email submissions.
- The shopping cart is a browser-based demonstration using local storage.
